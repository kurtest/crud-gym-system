# Gym Membership System CRUD Fullstack

## How to setup repo
 - use 'npm ci' after cloning repo

## Goal
 - Create a full-stack web system
 - Data is stored in MongoDB
 - System uses REST API built with Express
 - Front end built with HTML, CSS, and vanilla JS
  - JS is connects to the API using fetch
 - CRUD
## Technical Requirements
 - Collections: Events, Attendees, Registrations
 - Key Features: 
  - Add membership plans
  - register members under a plan
  - log daily attendance
  - flag expired memberships
  - count of active members
 - Full CRUD all working
 - REST API built with Express and Mongoose that returns JSON and uses the correct status codes
 - Front end HTML, CSS, vanilla JS only, using fetch
 - One extra feature which will either be filter or search
 - Basic validation and clear success or error messages
 - System can be presented without deployment
